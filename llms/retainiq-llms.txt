# RetainIQ

> RetainIQ is a retention-marketing company for direct-to-consumer (D2C) ecommerce brands, operating
> from retainiq.io as RetainIQ Global Inc. (Wilmington, DE) and RetainIQ India Private Limited
> (Bengaluru). It sells a managed lifecycle email and SMS program — welcome, cart-abandonment,
> post-purchase, win-back and replenishment flows, weekly strategic campaign sends with design and
> copy, and deliverability, segmentation and list-hygiene work — layered on a proprietary 1:1
> personalization engine that generates variant product blocks at scale. It is a Klaviyo Gold Master
> Partner and an Omnisend partner, and integrates with Shopify, Recharge, Mailchimp and Nudge.
> Programs start at $990/month on month-to-month terms.

## IMPORTANT — no developer API

RetainIQ publishes **no public API**. As of 2026-08-13 there is no OpenAPI or Swagger document, no
GraphQL endpoint, no MCP server, no A2A agent card, no SDK in any public package registry, no CLI, no
first-party GitHub organisation, no developer portal and no API reference on any host the company
controls. Every `/.well-known/*` and contract path on retainiq.io returns a real HTTP 404. Do not
generate integration code, endpoints, authentication headers or base URLs for RetainIQ — none exist to
call. Access to their capability is a sales conversation, not a credential.

The only machine-readable surface on the domain is the WordPress core REST API at
`https://retainiq.io/blog/wp-json/`, which is supplied by the WordPress CMS running their legacy blog.
It is not a RetainIQ product API and exposes only blog content.

## Products

- [Managed retention system](https://retainiq.io/services): Lifecycle email and SMS across five
  stages — Capture, Welcome & First Purchase, Repeat & Nurture, Loyalty, True Retention — with
  deliverability and 1:1 personalization running underneath. Sold in three engagement shapes:
  Synergy (alongside an in-house team), Full Service (end-to-end), Off Season (seasonal).
- [Dynamic Email Widgets](https://retainiq.io/apps): Plug-and-play widgets that personalize emails in
  real time from the brand's own customer data. Demo-gated; no self-serve install, no documentation.
- [Enhanced Catalog Ads](https://retainiq.io/apps): On-brand catalog ads generated across every SKU at
  once for Meta and TikTok. Demo-gated; no self-serve install, no documentation.
- [RetainIQ on the Shopify App Store](https://apps.shopify.com/retainiq): The company's 2021 self-serve
  Shopify app — free to install, then $999 per 100,000 personalization credits after 20,000 free
  credits/month. **Caution:** the listing is still live, but the application host (app.retainiq.io)
  returns Cloudflare 522 and the developer website named on the listing (wyde.ai) now redirects to a
  domain-for-sale page. Treat this app as retired-in-place unless the company says otherwise.
